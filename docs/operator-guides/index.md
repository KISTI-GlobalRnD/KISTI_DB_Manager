# Operator Guides

This section is for day-to-day operation.
It tells operators which command sequence to run, what artifacts to inspect, and when to stop.

## Use These Guides When

- You are running OpenAlex or similarly large nested JSON data
- You need a parquet-first workflow with later DB materialization
- You are restarting after an interruption
- You are preparing a release or documentation refresh
